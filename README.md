# RAT Kit

Набор: builder, payload-шаблон, RDP-агент, оператор, массовая рассылка.

## Требования

- Windows 10/11
- Python 3.11+ (python.org, галочка "Add Python to PATH")
- 4 ГБ RAM, 2 ГБ диска

## Установка

```bash
cd rat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
